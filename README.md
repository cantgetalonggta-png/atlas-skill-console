# Atlas Skill Console

TanStack Start / Vite command console for Grok Build skill ontology, inventory tree (381+ nodes), selector deployment packages, Archivist, connectors, and plugin MCP packs.

## Scripts

- `npm run dev` — preview on 8080
- `npm run build` — production build
- `npm run typecheck`

`/`, `/skills`, `/plugins`, `/archivist`, `/engine`, `/services`, `/tree`, `/selector`, `/deploy`, `/health`, `/api/*`
